# App 使用流程規範

這份文件記錄目前三個分頁的完整邏輯規範,給接續開發/測試時對照用。資料模型細節見 `HANDOFF.md`;這裡專注在「每一頁做什麼、怎麼互動」。

**重要**:這份文件混合了「已實作」跟「已定案但還沒實作」的內容,每個章節開頭都會標明狀態,不要假設全部都對應目前的程式碼。跟外層專案根目錄的 `README.md`(使用者手寫的規劃筆記)對照時,以 `README.md` 為最新決策來源。

## 整體結構

三個底部分頁,固定順序:**今日 → 薪資 → 設定**。全部是一般的 `expo-router` 路由畫面,沒有分頁是「觸發彈窗、不導航」的特例。

## 1. 今日 Tab(`src/app/index.tsx`)—— ✅ 已實作

**用途**:看月曆、瀏覽/建立/編輯/刪除班次,有「瀏覽」跟「排班」兩種模式。

**共用邏輯**:
- 模式、日期、各個 sheet 的開關狀態都存在 `src/store/ui-store.ts`(`todayMode`、`selectedDate`、`schedulingDate`、`dayDetail`、`deleteModeActive`、`editingShiftId`),不是畫面 local state。
- 有排班的日期在月曆格子上顯示橘色點(`dotColor: theme.primary`),休息日標記顯示灰色點(`theme.textSecondary`)。

### 瀏覽狀態(預設)

- 全螢幕行事曆 + 右下角懸浮圓形按鈕(`fab`,`theme.primary` 底色、白色 `add` icon)。
- 點懸浮按鈕 → `enterSchedulingMode()`,切換進排班狀態(同時把 `schedulingDate` 重置成當月 1 號)。
- 點月曆上任一天 → `setSelectedDate` + `openDayDetail(date)`,彈出 `src/components/day-detail-sheet.tsx`。
- `DayDetailSheet`:半截、可透過點背景或「返回」按鈕關閉。列出當天所有班次(含休息日標記),header 有「返回」+「刪除」(切換 `deleteModeActive`)。刪除模式開啟後每筆項目多一個垂圾桶圖示,點下去**直接刪除,不跳確認對話框**。點項目本身(非刪除圖示)→ `openShiftEdit(shiftId)`,疊一層 `src/components/shift-edit-sheet.tsx` 在上面。
- `ShiftEditSheet`:依這筆 `Shift` 有沒有 `shiftTypeId` 分兩種表單——有 → 只能改起訖時間/備註/國定假日/手動覆寫金額;沒有(手動輸入的臨時班次) → 整套欄位都能改(工作地點/時間/薪資/休息/加給)。都有刪除按鈕,直接刪除不用二次確認。

### 排班狀態

- 上方行事曆(`current` 綁 `schedulingDate`,點其他日期只換目標日期、不退出排班狀態)+ 下方 `src/components/scheduling-sheet.tsx`,**常駐、不可點背景或下滑關閉**,只能點 sheet 內的「退出」按鈕離開(`exitSchedulingMode()`)。
- Sheet 內容(local state `panel: 'list' | 'manual' | 'newShiftType'` 切換):
  - **班別清單**(依工作地點分組):點一項 = 立即 `addShift` 建立班次到 `schedulingDate`,並呼叫 `advanceSchedulingDate()`(+1 天),不跳確認。
  - **休息日**選項:建立 `isRestDay: true` 的 shift(不綁班別、無時間),同樣自動跳下一天。
  - **手動輸入**:展開內嵌表單(工作地點選填 chip、起訖時間、基本薪資、休息時間+計薪開關、深夜/假日加給開關、國定假日勾選、手動覆寫金額),送出後建立班次 + 跳下一天 + 收合回清單。
  - **新增班別**:展開精簡版 `ShiftType` 表單(選工作地點、名稱、起訖時間、休息時間、深夜/假日加給),建立後回到班別清單,不離開排班狀態。

### 計薪邏輯(現行實作,見 `src/lib/wage.ts` + `src/lib/resolve-shift-wage-input.ts`)

任何一筆 `Shift` 要算錢,先跑 `resolveShiftWageInput`:
1. `isRestDay` 或缺起訖時間 → 回傳 `null`,呼叫端跳過不計算。
2. `manualWageOverride` 有填 → 直接用這個數字。
3. 有 `shiftTypeId` → 從對應 `ShiftType` + 其 `Workplace.baseRate` 取得薪率/休息/深夜/假日規則。
4. 沒有 `shiftTypeId`(手動輸入) → 直接用 `Shift` 自己存的欄位。

工時計算:先處理跨夜(結束 ≤ 開始視為隔天),深夜加給依重疊分鐘數算,不計薪休息時間優先扣一般時段、扣完才反扣深夜時段。假日加成要「規則開關開」且「這筆班次勾了國定假日」兩者同時成立才套用。

⚠️ 這套計薪邏輯是照**舊版資料模型**寫的(`Workplace.baseRate` 單一薪率、沒有 `wageType`/`isFullDay` 概念)。下面「設定 Tab」規劃的新模型上線後,這裡要整套改寫,見該章節。

## 2. 薪資總覽 Tab(`src/app/wage.tsx`)—— ✅ 已實作(基礎版),⏳ README 規劃了尚未實作的功能

**已實作**:
- 月份切換(左右箭頭 + `yyyy 年 M 月`),`monthAnchor` 是畫面自己的 local state。
- 篩選範圍固定是「當月」(`startOfMonth`~`endOfMonth`)。
- 兩張大數字卡:當月總工時、預估總薪資。
- 依「工作地點」分組列表(用 `resolveShiftWorkplaceId` 判斷歸屬,手動班次沒指定工作地點的歸到「未指定」)。

**⏳ 尚未實作(來自 `README.md` 最新規劃,還沒動工)**:
- 範圍切換不是只有「月」,要加**週 / 雙週 / 月 / 年 / 自訂範圍**,預設仍是一個月。
- 除了總工時、總薪資,還要顯示**出勤天數**。
- 依工作地點拆算列表原本規劃要顯示「發薪日/薪資」,使用者已明確表示**這個先不做**。

## 3. 設定 Tab(`src/app/settings.tsx`)—— ⏳ 規劃版,尚未實作

**目前程式碼現況**:還是舊版模型——畫面內一個 pill 子分頁切換器(薪水設定 / 班別設定),`Workplace` 只有單一 `baseRate`,`ShiftType` 起訖時間一律必填、沒有 `isFullDay`/`wageType` 概念。**以下是取代它的新規劃**,實作時需要連動改 `src/db/schema.ts`、`src/lib/wage.ts`、`src/lib/resolve-shift-wage-input.ts`,以及 Tab1 那幾個 sheet 元件(它們目前吃的是舊 schema)。

### 整體結構(三層)

```
設定 Tab 根畫面(選項清單,目前只有「工作設定」一項,保留清單形式是因為之後會再加其他設定項目)
└─ 工作設定 → 工作主頁(上方 pill 子分頁:工作 / 排班)
    ├─ 工作(子分頁)
    └─ 排班(子分頁)
```

### 工作(子分頁)

**列表**:每個工作地點一張卡片(名稱 + 依計薪方式顯示的摘要:月薪顯示金額,非月薪顯示「依班別設定」提示),空清單顯示提示 + 新增按鈕。點卡片進編輯頁。

**編輯/新增頁欄位**:

| 欄位 | 顯示條件 | 備註 |
|---|---|---|
| 名稱 | 一律 | 必填 |
| 計薪方式:`月薪` / `非月薪` | 一律 | **新增時可選,編輯既有工作地點時鎖定不可改**(UI 顯示灰階唯讀 + 說明文字「建立後無法變更,避免過去排班紀錄的金額被回溯改變」) |
| 月薪金額 | `計薪方式=月薪` | 必填 |
| 起始日 / 目前是否仍在職 / 結束日 | `計薪方式=月薪` | 選填,「目前是否仍在職=否」建議填結束日 |
| 「薪水依班別設定」提示文字 | `計薪方式=非月薪` | 取代薪水欄位,引導去排班分頁 |

刪除:檢查底下有沒有班別綁定,有就擋下、不做連坐刪除。

### 排班(子分頁)

**列表**:依工作地點分組,每區塊標題是工作地點名稱,列出所屬班別簡述(名稱 + 起訖時間;**全日班別**顯示「全日」標籤取代時間)。每區塊下方各自有「新增班別」按鈕——**所屬工作地點由區塊帶入,表單裡不用再選一次**。沒有任何工作地點時,提示去「工作」子分頁先新增。

**編輯/新增頁欄位**:

| 欄位 | 顯示條件 | 備註 |
|---|---|---|
| 所屬工作地點 | 一律(唯讀) | 從區塊帶入 |
| 名稱 | 一律 | 必填 |
| 起訖時間 | 工作地點=月薪;或 非月薪 且 全日=關 | 必填 |
| 全日 開關 | 工作地點=非月薪 | |
| 時薪 | 非月薪 且 全日=關 | 必填 |
| 日薪金額 | 非月薪 且 全日=開 | 必填,取代起訖時間,不管做多久都算這個固定數字 |
| 休息時間(分鐘)+ 休息時間計薪開關 | 非月薪 且 全日=關 | 選填 |
| 深夜加給(開關+倍率+時段) | 非月薪 且 全日=關 | 選填 |
| 假日加給(開關+百分比) | 非月薪 且 全日=關 | 選填 |

月薪工作地點底下的班別:起訖時間只用來算出勤工時給薪資頁顯示,**不計逐班金額**。

刪除:檢查有沒有 `Shift` 綁定它,有就擋下。

### 舉例對照(幫助理解三種型態怎麼分類)

- 工地師傅,日薪 1600、時數不定 → 非月薪工作地點,全日班別
- 超商/手搖飲工讀,時薪制、有明確上下班時間 → 非月薪工作地點,非全日班別
- 正職辦公室固定月薪 → 月薪工作地點,班別只用來記出勤工時,不計薪

## Tab Bar —— ✅ 已實作

`src/components/app-tabs.tsx`(native)/ `app-tabs.web.tsx`(web)只有今日/薪資/設定三個項目,沒有特例攔截導航。今日 Tab 的 `tabPress`(native)/ `onExtraPress`(web)會呼叫 `resetToday()`:把 `todayMode` 重置回瀏覽狀態、`selectedDate` 重置回今天、關掉所有開著的 sheet——不管點的時候人在哪個分頁都會觸發。
