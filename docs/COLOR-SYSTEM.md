# 色彩系統

這份文件記錄目前 app 的配色決策,對應 `src/constants/theme.ts` 的 `Colors.light`/`Colors.dark`

- **主色**:深松綠 — 已確定/進行中的狀態
- **次色**:暖沙 — 預估/待入帳的狀態
- **提示色**:焦糖蜜棕 — 設定未完成之類的提醒,跟主次色的色系都拉得開,不會被誤認成任何一個既有語意
- **背景/卡片**:採用「反向分層」——頁面背景比一般設計更接近純白,卡片表面反而比背景多一階暖色,讓卡片像「紙鋪在白桌上」,質感更像紙,而不是傳統「卡片比背景亮」的做法

深色模式不是淺色模式直接反白,是照同一套邏輯重新校過:背景推到暖炭黑(不是純黑),卡片比背景亮一階(跟淺色模式的方向相反,因為淺色模式的背景已經是接近白色的極端值);主色/次色都調亮、降飽和度,不然在暗底上會糊掉或不夠顯眼(松綠原本的徽章底色跟卡片明度太接近,曾經反饋看不清楚,後來把徽章底色再調亮調飽和才解決)。

## 色票

### 背景 / 表面 / 邊框

| 用途                       | Key                  | 淺色      | 深色      |
| -------------------------- | -------------------- | --------- | --------- |
| 頁面背景                   | `background`         | `#FDFCF9` | `#1D1B17` |
| 卡片表面                   | `backgroundElement`  | `#F8F5EE` | `#272420` |
| 選中狀態底色(pill/segment) | `backgroundSelected` | `#D7E6E1` | `#2D4C3F` |
| 邊框線                     | `border`             | `#EAE4D5` | `#3B3730` |

### 文字

| 用途     | Key             | 淺色      | 深色      |
| -------- | --------------- | --------- | --------- |
| 主要文字 | `text`          | `#33312B` | `#ECE7DA` |
| 次要文字 | `textSecondary` | `#86827A` | `#9C9787` |

### 主色 · 深松綠(已確定 / 進行中)

| 用途                                    | Key           | 淺色      | 深色      |
| --------------------------------------- | ------------- | --------- | --------- |
| 填色(按鈕/FAB/選中 chip/發薪日曆總額卡) | `primary`     | `#3F6B5E` | `#4F8C79` |
| 淺底(已完成徽章/選中 pill 底色)         | `primarySoft` | `#D7E6E1` | `#2D4C3F` |
| 填色上的文字/icon 顏色                  | `onPrimary`   | `#FFFFFF` | `#0E1613` |

⚠️ 深色模式的 `primary` 特意調亮(比淺色模式的深松綠亮),所以填色上不能再套用白字——深色模式改用接近黑色的 `onPrimary`,不然對比不夠。任何「選中狀態底色變成 primary、文字變白」的地方都要讀 `theme.onPrimary`,不要寫死 `'#ffffff'`。

### 次色 · 暖沙(預估 / 待入帳)

| 用途                                | Key          | 淺色      | 深色      |
| ----------------------------------- | ------------ | --------- | --------- |
| 文字(直接當文字顏色用,例如預估金額) | `accent`     | `#5F4419` | `#E7CE9C` |
| 淺底(預估徽章/預估總計卡)           | `accentSoft` | `#F0E4CB` | `#3A2E1C` |

### 提示色 · 焦糖蜜棕(設定未完成 / 範本已跟篩選器不同步)

| 用途      | Key           | 淺色      | 深色      |
| --------- | ------------- | --------- | --------- |
| 色條/icon | `warning`     | `#BA8A5A` | `#C9986A` |
| 淺底      | `warningSoft` | `#F1E3D2` | `#362A1D` |
| 文字      | `warningText` | `#6B4A2C` | `#E3C4A3` |

用在「這份工作還沒設定發薪日」「篩選條件已跟範本不一樣」這類提醒,不是危險/錯誤(不會扣錢、不會壞掉),所以刻意不用紅色系,避免語意太重。視覺上搭配左側 3px 色條 + icon,不是只靠底色跟卡片區隔。

### 危險(維持不變)

| 用途             | Key      | 淺色      | 深色      |
| ---------------- | -------- | --------- | --------- |
| 刪除等破壞性動作 | `danger` | `#C0392B` | `#E0685C` |

## 用法慣例

- `src/hooks/use-theme.ts` 的 `useTheme()` 回傳目前色票(依系統色彩模式自動切換淺/深),元件裡一律透過 `theme.xxx` 讀,不要寫死 hex。
- 畫面統一用 `ThemedView`/`ThemedText`(讀 `theme` 的元件包裝)+ `StyleSheet.create` 寫版面,顏色透過 `theme.xxx` 或 `themeColor="xxx"` 帶入,不要新增其他 styling 方案。
- `StyleSheet.create` 裡的靜態樣式不能放會隨主題變的顏色(例如深色模式要換成 `onPrimary`),這種一定要用內嵌 `style={[styles.xxx, { color: theme.onPrimary }]}` 的寫法,不能寫死在 `StyleSheet.create` 裡。
